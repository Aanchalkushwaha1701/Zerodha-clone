# 📈 Zerodha Clone

A full-stack **Zerodha-inspired stock trading dashboard** built using React, Node.js, Express.js and MongoDB.

The project includes a responsive landing page, authentication system, trading dashboard, holdings, positions, orders and buy/sell functionality.

## 🚀 Live Demo

🔗 **Live Application:**  
https://zerodha-frontend-gzrt.onrender.com

---

## ✨ Features

### 🔐 Authentication
- User Signup
- User Login
- Authentication using backend APIs
- Secure API communication

### 📊 Dashboard
- Portfolio overview
- Holdings
- Positions
- Orders
- Trading interface
- Responsive dashboard UI

### 💰 Trading
- Buy stocks
- Sell stocks
- Enter quantity and price
- Create and store orders
- View placed orders

### 📦 Holdings & Positions
- View stock holdings
- View current positions
- Portfolio data fetched from backend APIs

### 🌐 Deployment
- Frontend deployed on Render
- Dashboard deployed on Render
- Backend deployed on Render
- MongoDB Atlas used for database
